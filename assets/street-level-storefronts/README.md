# Street-level storefront texture sheets

20 distinct storefront styles generated with built-in ImageGen. Exact prompts, original source paths, measured dimensions, and SHA-256 hashes are recorded in manifest.json.

Each sheet uses a roughly 4 x 4 modular layout, with display windows, entrances, blank fascia/sign panels, walls, shutters, vents, and trim. Signboards are blank for your own signage. Windows and door panes have dark opaque tones with no reflected scenery.

Use as sRGB base-color textures. Disable reflections/specular and clearcoat on the window material or mask to retain the nonreflective appearance in your engine. No normal, metallic, roughness, displacement, or emission maps are included.

These are unscaled original PNGs. The prompt requested 2048 x 2048; measured output dimensions are listed in the manifest. Layout boundaries are approximate, so use custom UV rectangles with inset sampling. Seamless tiling and engine import have not been validated. Some generated recess shading is present.
